## 🚀 快速开始

### 1. 加入协作
点击右上角 **⭐ Star** → **👁️ Watch** → 在 [TRIP_PLAN.md](./TRIP_PLAN.md) 里认领任务

### 2. 编辑方法
- **在线编辑**：点文件中 ✏️ 图标直接改
- **本地编辑**：`git clone git@github.com:lifengfa/korea-travel.git`

### 3. 勾选任务
把 `- [ ]` 改成 `- [x]`，GitHub 自动渲染成 ✅

### 4. 认领分工
在任务后面加 `@你的名字`，比如：
```
- [ ] 🚕 预定接送机 @ff
```

### 5. 开启 Project 看板（可选）
1. 打开 [Projects 页面](https://github.com/lifengfa/korea-travel/projects)
2. 点 **New project**
3. 选 **Board** 模板
4. 拖拽任务卡片管理进度
